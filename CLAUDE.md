# Project instructions

## Always update the user-facing surfaces

Any change to behaviour or features must update these in the **same** change, without being asked. An undocumented feature counts as incomplete.

| Surface | Files | What to check |
| --- | --- | --- |
| README | `README.md` | Features list, project structure tree, available-buttons table, behaviour and known-limits sections |
| Home page | `docs/index.html`, `docs/style.css` | `<meta name="description">` and `og:description`, hero copy, feature cards, browser mockup buttons, customization list, privacy section |
| Welcome page | `src/welcome/welcome.html`, `welcome.css` | Feature cards, Pro Tips |
| Options page | `src/options/options.html`, `options.js` | A toggle per feature, wired into the load and save key lists |

Also check whether a change makes existing copy **inaccurate**, not just incomplete. For example, adding the Markdown export made "zero data sent to external servers" wrong in both the README and the home page privacy section — that matters for Chrome Web Store review, not just tidiness.

`CHANGELOG.md` is generated by `npm run release`; never edit it by hand.

## Architecture notes

- Adding buttons to a new JIRA page should only need a new entry in `src/config/selectors.js`. Ask before changing source instead, and say why.
- Only `src/content.js` is a vite entry point, so anything it imports is bundled automatically. `src/background.js` is copied unbundled and cannot use `import`.
- `src/config/constants.js` is loaded as a raw ES module by the options page at runtime, so it must stay dependency-free.
- Every setting follows the `result[key] !== false` convention in `src/core/storage.js`, so settings default to on.
- The content script has no `chrome.storage.onChanged` listener, so a settings change needs a page reload to take effect.

## Conventions

- Double quotes, semicolons, 2-space indent; eslint enforces the first two.
- JSDoc on exported functions.
- Tests live next to the module they cover as `*.test.js` (`testMatch` is `src/**/*.test.js`).
- Run `npm run lint && npm test && npm run validate-manifest && npm run build` before calling a change done.
