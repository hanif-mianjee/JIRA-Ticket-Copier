Export Markdown Button

Download the whole ticket as a Markdown file — description, custom fields, linked and child work items, attachments and every comment — plus a file for each sub-task. The file is named PROJ-1234_Ticket_title.md and saved to your downloads folder, ready to hand to an AI coding agent.
Also export every sub-task as its own Markdown file, with its own PROJ-1235_files/ folder of attachments. The ticket's Child Work Items table links to each sub-task's file, and each sub-task's parent_file links back. Without Download attachments, Chrome asks once whether the site may download multiple files — choose Allow.
Put the exported ticket's file path on the clipboard, ready to paste into an AI agent. It is the full path on disk when Download attachments is on; otherwise Chrome does not reveal where the file was saved, so the file name is copied.
Also save the ticket's images and files into a PROJ-1234_files/ folder next to the Markdown file, and link to them by their full path on disk. Without this, images and attachments are links that need a Jira login, so an AI agent cannot open them. Chrome will ask permission to manage your downloads the first time you switch this on.

Search Results Copy Button

Adds a Copy list button to the header of issue search and saved filter pages, next to Share. It copies every result shown on the page, one line each.

Weekly Filter

Click the extension icon in the Chrome toolbar and choose Weekly filter to open a Jira search of the work you finished recently, with the dates already filled in.
Counted back from today, today included. 7 covers the same weekday last week up to now.
{{startDate}} and {{endDate}} become dates like 2026-11-19. Leave empty for the default.
Optional. Used when the current tab is not on Jira; otherwise the filter opens on the site you are looking at.
